### Required Files

for each dataset you need to provide the following files in the dataset/ directory:
- `<DATASET>_history.csv`: This file contains the historical baskets used for training and validation.
- `<DATASET>_future.csv`: This file contains the future baskets used for testing.
- The environment variable DATASETS in the .env file should be set to a comma-separated list of dataset names (e.g., `DATASETS=tafeng,instacart`). These names must concurr with the prefixes of the history and future files.

They need to be in the following format:

```csv
user_id,order_number,product_id
7,4,330
7,4,331
7,4,332
9,12,502
9,12,503
9,12,401
9,12,412
9,12,504
9,12,505
9,12,486
9,12,163
```

In order tog generate these files you need to preprocess your dataset. Examples on how to do this for tafeng,instacart and dunnhumby are provided in the [preprocess](./preprocess) directory.

### Quick Start

1. **Setup environment**: Install [conda](https://docs.conda.io/en/latest/miniconda.html) and configure datasets in .env
   ```bash
   cp .env.example .env
   # Edit .env file with your dataset configurations
   ```

2. **Run complete pipeline**:
   ```bash
   cd pipeline
   ./run_full_pipeline.sh | tee logfile.txt
   ```

The pipeline automatically creates and manages virtual environments for each method.
